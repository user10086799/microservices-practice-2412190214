## 项目名称

分布式购物系统

## 目标用户

- 普通消费者：浏览商品、加入购物车、下单并查看订单状态。
- 商家：发布商品、管理库存、处理发货。
- 系统管理员：管理用户与商品分类，查看系统运行状态。

## 准备优先实现的业务场景

买家浏览商品并提交订单：查看商品信息，选择商品后创建一笔待支付订单。支付、发货和评价留到后续周次。

## 两个核心模型

- 商品：名称、描述、价格、库存数量。
- 订单：所属买家、包含的商品、数量、金额和订单状态。

本周工程范围只包括应用启动、`application.yml`、`GET /api/hello` 和启动测试，不包含上述模型的代码、数据库和业务接口。
